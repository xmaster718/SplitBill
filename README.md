# SplitBill

## Структура базы данных

1. В phpMyAdmin выберите базу `splitbill`.
2. Откройте вкладку **Импорт** и выберите файл `database/schema.sql`.
3. Запустите импорт. Скрипт создаст таблицы групп, участников групп, расходов и долей расходов; существующую таблицу `users` он не изменяет.

Создатель группы должен также добавляться в `group_members` с ролью `owner`. Для каждого расхода в `expense_splits` нужно записывать долю каждого участника; сумма долей должна совпадать с суммой расхода. При удалении расхода его доли удаляются автоматически. Участники и группы, на которые ссылаются расходы, защищены внешними ключами.
