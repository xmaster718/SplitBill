# SplitBill — сервис для сплита счёта и совместных расходов

Веб-приложение для деления общих расходов: поездка, съём квартиры, ужин с друзьями. Создаёте группу, приглашаете людей, вносите траты — сервис считает, **кто кому и сколько должен**, и предлагает **минимум переводов**.

Учебный проект курса Advanced Backend & DevOps. Стек: **HTML / CSS / JavaScript** (без сборки) + **PHP 8** (PDO) + **MySQL / MariaDB**.

## Возможности

- Регистрация, вход, выход; роли `user` и `admin`; админ-панель
- Группы, вход по коду или ссылке-приглашению, участники без аккаунта («гости»)
- Расходы: деление **поровну** или **по суммам**, дата, плательщик
- Баланс каждого участника и **упрощение долгов** (минимум переводов), кнопка «Отметить оплаченным»
- Поиск, фильтр по плательщику, сортировка, пагинация
- Публичная главная с быстрым калькулятором счёта (работает без входа) и SEO-разметкой
- Адаптивный интерфейс (телефон и компьютер)

## Запуск в XAMPP (как у преподавателя)

1. Установите XAMPP (PHP 8.x), запустите в панели **Apache** и **MySQL**. Нужны расширения PHP `pdo_mysql` и `mbstring` — в XAMPP они включены.
2. Положите проект в `C:\xampp\htdocs\SplitBill` (например, `git clone` прямо туда).
3. Откройте `http://localhost/phpmyadmin` → **Создать БД** `splitbill`, сравнение `utf8mb4_unicode_ci` → выберите её → **Импорт** → файл `sql/schema.sql`.
4. Если у MySQL есть пароль (в XAMPP по умолчанию его нет): скопируйте `public/api/config.local.example.php` в `config.local.php` и впишите данные.
5. Откройте **http://localhost/SplitBill/public/**

Проверка: `http://localhost/SplitBill/public/api/health.php` должен вернуть `{"status":"ok","db":"up",...}`.

## Запуск в Docker

```bash
docker compose up --build
```
Сайт: **http://localhost:8080**. База создаётся и заполняется схемой автоматически. Пароли можно поменять через файл `.env` (см. `.env.example`).

## Как стать администратором

Зарегистрируйтесь на сайте, затем в phpMyAdmin → вкладка SQL:

```sql
UPDATE users SET role = 'admin' WHERE email = 'ваш@email.com';
```
Обновите страницу — в шапке появится «Админ-панель».

## API

Все ответы — JSON. Авторизация: заголовок `Authorization: Bearer <токен>`. Ошибки: `{"error": "понятный текст"}` и подходящий HTTP-статус (400, 401, 403, 404, 409, 429).

| Метод | Адрес | Что делает |
|---|---|---|
| POST | `/api/register.php` | регистрация → токен |
| POST | `/api/login.php` | вход → токен (8 неудачных попыток за 15 минут → 429) |
| POST | `/api/logout.php` | выход, токен перестаёт действовать |
| GET | `/api/me.php` | данные текущего пользователя |
| GET / POST / DELETE | `/api/groups.php` | список групп / создать / удалить (только создатель) |
| POST | `/api/join.php` | войти в группу по коду приглашения |
| GET / POST / DELETE | `/api/members.php` | участники группы |
| GET / POST / DELETE | `/api/expenses.php` | расходы и переводы; GET: `page`, `per_page`, `q`, `sort`, `paid_by` |
| GET | `/api/balances.php?group_id=` | балансы и список переводов для закрытия долгов |
| GET / DELETE | `/api/admin.php` | статистика и управление (только admin) |
| GET | `/api/health.php` | проверка «жив ли сервис» (для мониторинга) |

## Безопасность (что говорить на защите)

| Угроза | Как закрыто |
|---|---|
| Пароли | Только хэш `password_hash` (bcrypt), в базе паролей нет |
| SQL-инъекции | Везде подготовленные запросы PDO (`EMULATE_PREPARES=false`); поле сортировки — только из белого списка |
| XSS | Весь текст пользователя выводится через `textContent` (никакого `innerHTML`), плюс заголовок CSP: скрипты только с нашего сайта |
| CSRF | Вход по токену в заголовке, а не по cookie — браузер сам такой токен в чужой запрос не подставит |
| Подбор пароля | Лимит неудачных попыток входа на email |
| Чужие данные | Каждый запрос проверяет, что пользователь состоит в группе; права на удаление — только автор записи или создатель группы |
| Токены | В базе хранится SHA-256 от токена, срок жизни 7 дней, при выходе удаляется |
| Секреты | Пароль БД — в переменных окружения или в `config.local.php`, который в `.gitignore` |

## Как считаются деньги (важно уметь объяснить)

- Все суммы — **целые числа в копейках/тиынах**. Дробных чисел нет, поэтому нет и ошибок округления.
- Деление поровну: `100,00 ₸ на троих` → `33,34 + 33,33 + 33,33`. Лишняя копейка достаётся первому, **сумма долей всегда ровно равна сумме расхода**.
- Баланс участника = сколько он заплатил − сумма его долей. Сумма балансов всей группы всегда 0.
- Упрощение долгов: должников и кредиторов сортируем по размеру и погашаем крупнейший долг крупнейшим требованием. Получается не больше `N − 1` переводов на `N` человек.
- Перевод долга записывается как особый расход (`kind = 'payment'`), поэтому баланс пересчитывается тем же кодом без исключений.

## Размещение в интернете

**Вариант А — обычный PHP-хостинг с MySQL (проще всего).**
1. Заведите аккаунт на хостинге с PHP 8 и MySQL (поищите «free PHP MySQL hosting», проверьте актуальные условия и ограничения тарифа) и создайте в панели базу данных.
2. В phpMyAdmin хостинга выберите созданную БД → **Импорт** → `sql/schema.sql`.
3. Скопируйте `public/api/config.local.example.php` в `config.local.php` и впишите хост, имя БД, пользователя и пароль **из панели хостинга**.
4. Загрузите **содержимое папки `public/`** (включая скрытый `.htaccess`) в папку сайта (`htdocs` / `public_html`) по FTP или через файловый менеджер.
5. Откройте `https://ваш-сайт/api/health.php`. Если вместо JSON приходит HTML-страница хостинга, значит хостинг блокирует запросы к API: ищите в панели настройки защиты/«anti-bot» или выберите другой хостинг.

**Вариант Б — Docker-платформа** (Render, Railway, Koyeb и подобные). Dockerfile уже готов. Укажите переменные `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS` от облачной MySQL и импортируйте в неё `sql/schema.sql`. Этот вариант подходит для недель 11–14 (контейнеры, CI/CD, деплой).

## Как попасть в Google

1. Нужен **публичный адрес с HTTPS** (после размещения выше).
2. Замените `https://splitbill.example.com` на ваш адрес. В VS Code: `Ctrl+Shift+H` → найти → заменить во всех файлах (встречается в `index.html`, `robots.txt`, `sitemap.xml`).
3. Зайдите в **Google Search Console**, добавьте сайт, подтвердите владение, в разделе **Sitemaps** добавьте `sitemap.xml`, а в «Проверка URL» нажмите **«Запросить индексацию»** для главной.
4. Индексация занимает от нескольких дней до пары недель. Ссылки на сайт из README репозитория, профиля GitHub и соцсетей ускоряют процесс.

Честно: попасть в индекс можно, а вот занять высокую позицию по общим запросам вроде «калькулятор счёта» с первого дня нельзя. Поиск по названию сайта находится быстрее всего.

В Google будет индексироваться главная страница (`index.html`) с описанием, FAQ и структурированными данными. Страницы входа и приложения помечены `noindex`: им незачем быть в поиске.
