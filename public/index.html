Группы и приглашения

Создайте группу и позовите друзей по короткому коду или ссылке. Участников без аккаунта можно добавить по имени.

Поровну или по суммам

Делите расход между выбранными людьми поровну либо задайте точную долю каждого.

Кто кому должен

Баланс каждого участника считается автоматически, до копейки и без накопления ошибок округления.

Минимум переводов

Вместо десятка встречных долгов сервис предлагает короткий список переводов, которые закрывают всё.

Отметка о переводе

Перевели деньги — нажмите одну кнопку, и долг исчезнет из расчёта. История остаётся в группе.

Поиск и фильтры

Найдите нужный расход по описанию, отсортируйте по сумме или дате, отфильтруйте по плательщику.

Как это работает

Создайте группу

Назовите её, например «Поездка в Алматы», и пригласите участников.

Добавляйте расходы

Укажите сумму, кто заплатил и между кем она делится.

Закройте долги

Смотрите, кто кому переводит, и отмечайте переводы по мере оплаты.

Частые вопросы

Как поделить счёт поровну?

Введите сумму и число людей в калькуляторе выше. Для регулярных трат создайте группу: отметьте участников расхода, и сервис разделит сумму до копейки.

Нужно ли друзьям регистрироваться?

Нет. Участника можно добавить просто по имени. Если друг зарегистрируется, он войдёт в группу по коду приглашения и увидит все расходы.

Как работает расчёт «кто кому должен»?

Для каждого участника считается разница между тем, что он заплатил, и суммой его долей. Затем сервис подбирает минимальный набор переводов, который обнуляет все балансы.

Мои данные в безопасности?

Пароли хранятся только в виде хэша, доступ к группе есть только у её участников, а весь вводимый текст отображается как текст и не может выполнить код на странице.
